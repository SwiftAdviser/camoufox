# Camoufox GeoIP sponsor preview

This is a review preview of the published [GeoIP page](https://camoufox.com/python/geoip/), captured on 6 October 2026, with a compact ProxyLane sponsor description. The public Camoufox main branch does not contain the Retype website source for this page. This directory preserves the published page structure and loads its existing Retype styles, runtime and brand assets from camoufox.com. Copyright and official canonical attribution remain intact. It is not the official documentation release.

Open `index.html` through a static HTTP server, or use the fork's GitHub Pages preview. To serve locally from the repository:

```sh
python3 -m http.server 8791 --directory docs --bind 127.0.0.1
```

Visit <http://127.0.0.1:8791/geoip-preview/>. An internet connection is needed for the upstream Retype assets. The modified source for the page's Copy as Markdown action is `geoip.md`. Other documentation navigation links open the official website. Page-view and sponsor-balance tracking scripts are omitted from this review preview.

Only the ProxyLane sponsor body changes. Other sponsors, code examples, card styling, banner dimensions and order are preserved. The existing CAMOULANE35 line is retained from the host page; it does not establish eligibility or compatibility with the separately advertised paid trial.
